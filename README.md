NOVA DRIFT — Void Salvage: a neon top-down arena shooter. Pilot a salvage ship through 10 waves of hostile drones, weavers and brutes, collect salvage, buy upgrades between waves, and sink the LEVIATHAN boss to win. Keyboard + mouse, no build step, no network — just open it and fly.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any static HTTP server and open `game/index.html`.
